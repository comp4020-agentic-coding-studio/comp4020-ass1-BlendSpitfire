## What did this work change about who I want to be as a software developer?

Compared to the previous two crits, this assignment required far more changes,
and that exposed quite a few problems in my current workflow — which is why
`CLAUDE.md` finally picked up some habits that should have a real effect going
forward.

A recent piece of news feels relevant here: Anthropic announced that Claude
Code would switch to "auto mode" (automatic AI-classifier review) by default,
replacing step-by-step manual approval, after finding manual review was
largely theatre — humans caught only 13.6% of disguised dangerous
instructions versus 89% for auto mode, and human accuracy fell further the
longer a session ran, while the machine stayed stable.

That matches my own experience. The real time sink on an assignment like this
is often not the work itself but the gap between a prompt popping up for
approval and my attention actually coming back to it — auto mode cuts that
dramatically. The cost is some potential risk, but it's small next to the drag
on efficiency, so I treat it as a tradeoff. My hedge is committing frequently,
so anything that goes wrong inside the project can be rolled back; for
instructions from outside the project, enough guardrails already exist that
I'm not too worried. So at this point I default to auto mode too.
